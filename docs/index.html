Build an XGS image

An OPNsense image for a Sophos XGS appliance, with the os-xgs-npu driver and plugin in it.

Nothing built here has been booted on an appliance. The build runs on a GitHub runner, which has no Sophos hardware attached to it. Burn an image and boot it before relying on it.

What pressing that does

  1. This page sends you to the repository's new issue form, filled in from your choices above. It calls nothing and holds no credentials.
  2. You press Submit new issue there. Nothing runs until you do.
  3. A workflow reads the issue and starts the build, and comments with a link to the run.
  4. When it finishes, the image is a workflow artifact on that run. It expires on its own.

The build only runs for the account that owns the repository, so that nobody else spends your Actions minutes. To build one for yourself, fork the repository, enable Pages on your fork, and use your fork's copy of this page - it will file the issue on your fork. That is the licence position in CONTRIBUTING.md: your build, your artifact, your storage.
